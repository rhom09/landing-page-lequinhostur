Estabelecer a fundação de SEO para a Landing Page LekinhosTUR sem migração de framework, maximizando o que é possível dentro de uma SPA React/Vite.

## Decisão Arquitetural: SPA vs SSR

**Recomendação: Permanecer SPA (Vite) nesta fase.**

| Critério | SPA (Vite) | SSR (Next.js) |
|----------|-----------|---------------|
| Esforço de migração | Nenhum | ~2-3 dias de reescrita |
| SEO para Landing Page | Suficiente com meta tags estáticas + JSON-LD | Ideal, mas overengineering para 1 página |
| Custo-benefício | ✅ Alto | ❌ Desproporcional |
| Risco | Nenhum | Quebra de integração Sanity, rotas, Vercel config |

**Justificativa:** O site é uma Single Landing Page com conteúdo semi-estático. Meta tags no `index.html` + JSON-LD inline + `robots.txt` + `sitemap.xml` cobrem 90% das necessidades de SEO para este tipo de projeto. A migração para Next.js seria justificável apenas se o projeto evoluísse para um multi-page com blog ou catálogo dinâmico de destinos.

## Tarefas

### Tarefa 1: Meta Tags & Open Graph (index.html)

**Arquivos:** `app/index.html`

- Otimizar `<title>` com keywords de conversão
- Adicionar meta tags Open Graph completas (`og:title`, `og:description`, `og:image`, `og:url`, `og:type`, `og:locale`)
- Adicionar Twitter Card meta tags
- Adicionar `<link rel="canonical">`
- Adicionar meta `theme-color`

### Tarefa 2: robots.txt + sitemap.xml

**Arquivos:** `app/public/robots.txt`, `app/public/sitemap.xml`

- Criar `robots.txt` permitindo crawling completo
- Criar `sitemap.xml` estático com a URL principal

### Tarefa 3: Structured Data (JSON-LD)

**Arquivos:** `app/index.html`

- Adicionar JSON-LD `Organization` (nome, logo, redes sociais, contato)
- Adicionar JSON-LD `LocalBusiness` (endereço, telefone, horário)
- Adicionar JSON-LD `WebSite` (search action potencial)

### Tarefa 4: Semântica HTML

**Arquivos:** `app/src/sections/Navbar.tsx`, `app/src/sections/Footer.tsx`

- Garantir que `<nav>` use `aria-label`
- Verificar hierarquia de headings (h1 único, h2 por seção)
- Adicionar `role` e `aria-label` onde necessário

### Tarefa 5: Limpeza & Otimização Final

**Arquivos:** `app/src/pages/Home.tsx`

- Remover `Home.tsx` (arquivo boilerplate do Vite não utilizado)
- Verificar se todas as imagens têm `alt` descritivo com keywords

## Critérios de Sucesso

1. ✅ Meta tags Open Graph renderizam preview correto ao compartilhar link no WhatsApp/Instagram
2. ✅ `robots.txt` e `sitemap.xml` acessíveis em produção
3. ✅ JSON-LD validável no [Google Rich Results Test](https://search.google.com/test/rich-results)
4. ✅ Hierarquia de headings sem pulos (h1 → h2 → h3)
5. ✅ Score SEO do Lighthouse ≥ 90
