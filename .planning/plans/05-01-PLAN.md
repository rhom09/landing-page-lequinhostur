### Tarefa 9: UI-09 — Scroll progress bar

**Arquivos:** `app/src/components/ScrollProgressBar.tsx` (novo), `app/src/App.tsx`

**Problema:** Sem indicador visual de progresso de leitura na página.

**Ações:**

1. Criar `app/src/components/ScrollProgressBar.tsx`:
   ```tsx
   import { useState, useEffect } from 'react';

   export function ScrollProgressBar() {
     const [progress, setProgress] = useState(0);

     useEffect(() => {
       const handleScroll = () => {
         const scrollTop = window.scrollY;
         const docHeight = document.documentElement.scrollHeight - window.innerHeight;
         setProgress(docHeight > 0 ? (scrollTop / docHeight) * 100 : 0);
       };
       window.addEventListener('scroll', handleScroll, { passive: true });
       return () => window.removeEventListener('scroll', handleScroll);
     }, []);

     return (
       <div className="fixed top-0 left-0 right-0 h-[2px] z-[60] bg-transparent">
         <div
           className="h-full bg-accent transition-[width] duration-150 ease-out"
           style={{ width: `${progress}%` }}
         />
       </div>
     );
   }
   ```
2. Importar e renderizar `<ScrollProgressBar />` no `App.tsx` antes da Navbar.

**Verificação:**
- Barra de 2px no topo da página avança com scroll
- Cor `accent` (amarelo) visível sobre a Navbar
- Desaparece no topo (0%) e preenche totalmente no final (100%)

### Tarefa 15: UI-15 — DRY: extrair `handleNavClick` para hook

**Arquivos:** `app/src/hooks/useSmoothScroll.ts` (novo), `app/src/sections/Navbar.tsx`, `app/src/sections/Footer.tsx`, `app/src/sections/BottomNav.tsx`

**Ações:**

1. Criar `app/src/hooks/useSmoothScroll.ts`:
   ```ts
   export function useSmoothScroll() {
     return (e: React.MouseEvent<HTMLAnchorElement>, href: string) => {
       e.preventDefault();
       const target = document.querySelector(href);
       if (target) {
         const isMobile = window.innerWidth < 1024;
         const offset = isMobile ? 80 : 100;
         const top = target.getBoundingClientRect().top + window.scrollY - offset;
         window.scrollTo({ top, behavior: 'smooth' });
       }
     };
   }
   ```
2. Importar e usar em Navbar, Footer e BottomNav. Remover funções locais.

**Verificação:**
- Uma única implementação de smooth scroll
- `grep -r "const handleNavClick" app/src/` retorna zero resultados
