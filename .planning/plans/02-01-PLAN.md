# Plano de Fase 02: Performance & Otimização de Assets (Atualizado)

Este plano detalha as etapas técnicas para atingir a meta de performance "Green Score" (90+) no Lighthouse Mobile para a Landing Page LekinhosTUR.

## Objetivos
1. Atingir 90+ em Performance no Lighthouse Mobile.
2. Reduzir o LCP (Largest Contentful Paint) para menos de 2.5s em 4G.
3. Otimizar todos os ativos estáticos (logo, imagens de destinos).
4. Reduzir o bundle JS inicial através de code splitting.

## 🛠️ Passo 1: Auditoria e Infraestrutura
- [x] Instalar `rollup-plugin-visualizer` para análise de bundle.
- [x] Rodar auditoria inicial do Lighthouse e salvar o relatório.
- [x] Configurar um script básico para conversão de imagens (`app/scripts/optimize-images.py`).

## 🖼️ Passo 2: Otimização de Assets Estáticos
- [x] **Logo Mobile**: Comprimir `logo-mobile.png` (atualmente 1MB) e converter para WebP (~50KB alvo).
- [x] **Favicon**: Substituir `favicon.png` (400KB) por um arquivo .ico or .png otimizado (~16-32KB).
- [x] **Imagens de Destino**: Converter todas as imagens `.jpg` em `public/` para `.webp`.
- [x] **Logos Gerais**: Otimizar `logo.png`, `logo-nav.png` e `logo-footer.png`.

## 📦 Passo 3: Code Splitting e JS Bundle
- [x] Identificar componentes pesados (`CalendarioExcursoes`, `SocialProof`).
- [x] Implementar `React.lazy()` e `Suspense` para esses componentes.
- [x] Verificar se há importações de bibliotecas pesadas (como `recharts`) e garantir que estão sendo importadas de forma eficiente.

## 🚀 Passo 4: Componente de Imagem Otimizado
- [x] Criar um componente `OptimizedImage` em `src/components/common/`.
- [x] Implementar suporte a `loading="lazy"`.
- [x] Adicionar suporte a `fetchpriority="high"` para a imagem do Hero (LCP).
- [x] Implementar lógica de fallback para imagens do Sanity e locais.

## ✅ Passo 5: Validação Final
- [x] Rodar auditoria final do Lighthouse Mobile.
- [x] Verificar compatibilidade de imagens em navegadores antigos.
- [x] Atualizar documentação `STATE.md` com os novos scores.

## Critérios de Aceite
- Score Lighthouse Performance Mobile >= 90.
- Nenhuma imagem individual acima de 200KB no carregamento inicial.
- Tempo de carregamento total reduzido em pelo menos 50%.
